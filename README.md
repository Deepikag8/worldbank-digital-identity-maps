# 🌍 World Bank Digital Identity Maps & Blockchain Integration

This repository explores global disparities in digital public infrastructure using a combination of official ID4D datasets, policy visualizations, and analytical modeling tools. It focuses on **digital identity coverage**, **cryptocurrency adoption**, and the potential for **blockchain-based governance** in public data systems.

🔗 [Live Repository](https://github.com/Deepikag8/worldbank-digital-identity-maps)

---

## 📁 Project Structure

| Folder/File              | Description |
|--------------------------|-------------|
| `images/`                | ID4D digital identity maps and a blockchain adoption chart |
| `data/`                  | Cryptocurrency ownership by country (Statista/World Bank sources) |
| `reports/`               | PowerPoint on blockchain adoption and digital transformation in governance |
| `functions/`             | R scripts to generate population-weighted maps |
| `wb-data-dive.qmd`       | Main Quarto script using IAMC-style scenario visualizations |

---

## 🔍 Key Themes

- **Digital ID Access & Equity:** Visualizing birth certificate registration, digital ID verification, and online access by region
- **Blockchain in Public Systems:** Role of blockchain in identity verification, data security, and decentralized governance
- **Cryptocurrency as a Proxy:** Ownership trends and potential for integrating financial identity layers
- **Geospatial Visualization:** R-generated maps aligned with IAMC standards for governance-based differentiation

---

## 🧠 Methods

- R (tidyverse, ggplot2, magclass, madrat)  
- Scenario modeling using governance indicators  
- Regional aggregation with population weighting  
- Visual storytelling using Quarto + Statista insights
